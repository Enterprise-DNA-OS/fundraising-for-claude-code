# Why no front end

Fundraising work starts with a question: who needs a call, which pledge is late, or why the appeal total changed. The CLI answers from owned records. Read-only HTML snapshots and paperwork use brand.json, with no hosted app or service required. The agent reads the same commands as you.

A dedicated screen adds phone entry, offline work, scanning, visual navigation and role-specific forms. This base does not offer those. Shared access needs a configured database, scoped credentials, access policy and tested backups. Enterprise DNA can build the screens, integrations and operating process your charity needs through Omni by Enterprise DNA.

There are no payment credentials, automatic sends or live vendor connections. This is a donor operations base, not full NXT feature parity.
